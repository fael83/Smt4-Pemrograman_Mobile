Aplikasi cuaca sederhana berbasis Flutter yang terintegrasi dengan Firebase Authentication dan OpenWeather API. Langkah-langkah membuat aplikasi ini yang pertama yaitu membuat tampilan login, menghubungkan dengan firebase, membuat tampilan cuaca serta mencari dan menampilkan informasi cuaca secara real-time berdasarkan nama kota, termasuk suhu terkini yang sudah terkoneksi dengan API weather.
